# ORANGE PLAY

Статический прототип магазина аренды игр PlayStation 4 и PlayStation 5. Публикация настроена для GitHub Pages.

## Возможности
- адаптивный каталог в графитовом стиле с оранжевым акцентом;
- поиск, фильтр PS4/PS5 и сортировка;
- корзина и демонстрационное оформление;
- каталог вынесен в `data/products.json`;
- только профиль аренды П2;
- цены рассчитаны по правилу: подтверждённая цена источника + 200 ₽.

## Важно
Сейчас добавлены только позиции, для которых удалось подтвердить П2 и тариф на 7 дней. Другие сроки не придуманы. Доступность нужно проверять повторно перед запуском. Planet Zoo 2 помечена как партнёрская позиция.

Это демонстрационная версия: регистрация, оплата, серверная обработка заказов и выдача аккаунтов не подключены. Обложки игр пока представлены графическими заглушками.

## Публикация
После включения Pages с источником **GitHub Actions** сайт будет автоматически публиковаться при обновлении ветки main.
